Instalar como PWAsin descargar nada

1Abrí el sitio en Chrome Android
2Tocá los 3 puntitos ⋮ → "Agregar a pantalla de inicio"
3Tocá "Instalar"
La PWA funciona como app: offline, icono propio, sin navegador y notificaciones.
⚙️

Compilar el APKsin Android Studio

1Subí la carpeta ZonaHackApp/ a un repo de GitHub
2El workflow build-apk.yml compila solo en la nube
3En Actions bajás el artefacto ZonaHack-APK
4O tocá Run workflow para recompilar cuando quieras
💡 Alternativa sin GitHub: PWA Builder — pegá la URL del sitio → Start → Android → descargá el .apk.
🔧 Cualquier cambio en ZonaHackApp/ se recompila automáticamente al subirlo.
