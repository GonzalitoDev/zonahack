🔑 API Key (opcional)

Por defecto la API está abierta (con límite de 25 peticiones/min por IP). Para protegerla: el dueño agrega claves en api_keys.json del VPS (ej: ["mi-clave-secreta"]) y desde ahí se requiere &api_key=mi-clave-secreta.
