📘 ZONALANG · GUÍA RÁPIDA

ZonaLang es un lenguaje de programación propio con intérprete en el navegador. Sintaxis en español, sencilla y completa.

📣 Imprimir en pantalla

imprimir("Hola, Gonza!")
imprimir("Resultado: " + 42)

🔀 Si / Sino

si (edad >= 18) {
  imprimir("Mayor de edad")
} sino {
  imprimir("Menor")
}

🔁 Mientras

i = 1
mientras (i <= 5) {
  imprimir(i)
  i = i + 1
}

🔁 Para

para (j = 0; j < 10; j = j + 1) {
  imprimir(j)
}

🧩 Funciones

funcion sumar(a, b) {
  retornar a + b
}
imprimir(sumar(3, 4))  # 7

⚙️ Funciones incorporadas

📌 Características

  • Tipos: número, texto, booleano y nada.
  • Variables automáticas (no hace falta declarar).
  • Funciones recursivas.
  • Ámbitos (scope) por bloques.
  • Errores claros en español.

💡 EJEMPLOS

Calculadora

a = 12
b = 4
imprimir("Suma: " + (a + b))
imprimir("Resta: " + (a - b))
imprimir("Mult: " + (a * b))
imprimir("Div: " + (a / b))
imprimir("Mod: " + (a % b))

Fibonacci

funcion fib(n) {
  si (n <= 1) { retornar n }
  retornar fib(n - 1) + fib(n - 2)
}
para (i = 0; i <= 10; i = i + 1) {
  imprimir("fib(" + i + ") = " + fib(i))
}

Tabla de multiplicar

tabla = 7
para (i = 1; i <= 10; i = i + 1) {
  imprimir(tabla + " x " + i + " = " + (tabla * i))
}

Contador regresivo

n = 10
mientras (n > 0) {
  imprimir("T-" + n)
  n = n - 1
}
