# Ejemplos para enseñar programación (Python)

Carpeta con ejemplos progresivos, pensados para enseñar programación desde cero.
Cada archivo se puede ejecutar de forma independiente con:

```
python nombre_del_archivo.py
```

## Orden recomendado

1. **01_variables_y_tipos.py** — variables, tipos de datos (str, int, float, bool)
2. **02_condicionales.py** — if / elif / else, operadores de comparación y lógicos
3. **03_bucles.py** — for, while, break, continue
4. **04_funciones.py** — definir funciones, parámetros, valores por defecto, retorno
5. **05_listas_y_diccionarios.py** — listas, diccionarios, listas de diccionarios
6. **06_manejo_de_errores.py** — try / except / finally
7. **07_programacion_orientada_a_objetos.py** — clases, objetos, herencia
8. **08_archivos.py** — leer y escribir archivos de texto
9. **09_proyecto_final_lista_de_tareas.py** — proyecto que integra todo lo anterior

## Cómo usarlos

- Cada archivo tiene comentarios explicando el "por qué", no solo el "qué".
- Al final de cada archivo hay un **EJERCICIO PROPUESTO** para practicar solo/a.
- Se recomienda seguir el orden numérico, ya que cada tema se apoya en el anterior.

## Requisitos

Solo necesitas tener Python instalado (3.8 o superior). Verifica con:

```
python --version
```
